# FacetPDF Studio App Store Copy

## Name

FacetPDF Studio

## Subtitle

Read, edit & sign PDFs.

## Promotional Text

Convert images, text, RTF and HTML to PDF on device. Faster OCR, forms, signatures, page tools and export.

## Short Description

FacetPDF Studio helps you read, scan, annotate, sign, organize, convert, compress, and export PDFs on iPhone and iPad while keeping document work on device.

## Feature Highlights

- On-device file-to-PDF conversion for images, text, RTF, and HTML.
- PDF reading, search, annotation, signatures, stamps, page organization, merge, compact export, and flattened export.
- Camera scanning and OCR-focused workflows for turning paper and files into practical PDF documents.
- No account required and no remote document backend.
